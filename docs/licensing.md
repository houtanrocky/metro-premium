# Publication and licensing policy

Source notices: [Divar official dataset](https://huggingface.co/datasets/divarofficial/real_estate_ads) declares ODbL; [OSM copyright](https://www.openstreetmap.org/copyright) attributes © OpenStreetMap contributors. The governing text is [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Code is MIT; database rights remain separate.

ODbL distinguishes databases, derivative databases and produced works. Attribution alone is not the whole obligation: public use of a derivative database can trigger share-alike and access requirements. Before distributing combined listing/OSM tables, classify the output and make any required machine-readable derivative database or alteration method available under the appropriate terms. Do not redistribute confidential data to satisfy a license; choose compatible publication scope instead.

This release publishes no row-level housing database. It conservatively treats structured source-derived aggregates as ODbL and includes their transformation code and source identifiers. Actual street geometry is OSM-derived ODbL data; notices accompany its download and map attribution. PNG/SVG source-count graphics include source/date/scope metadata; preserve attribution when sharing. Review larger database releases before publication.

No public OSM tile requests are made by default. An optional style URL must use a provider with suitable license, quotas and attribution. Never bulk-download or prefetch public OSM tiles; follow the [tile policy](https://operations.osmfoundation.org/policies/tiles/). A public frontend configuration value is not a safe place for secrets. Keep font package OFL notices with distributed font assets.
