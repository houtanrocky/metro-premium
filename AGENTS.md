# MetroPremium scientific and implementation rules

Use official, revision-pinned inputs. Never fabricate observations, geography, citations or findings. Source-unit currency is mandatory until denomination is explicitly verified. Do not pool nominal prices over years. Raw data and individual listing coordinates must never enter Git or public exports. Keep synthetic fixtures clearly named and out of the default empirical website.

Public metro routes require geometry and topology verification; never connect station dots to invent track geometry. Missing entrances and failed routes stay missing. Distinguish a later reference network from historical infrastructure. Preserve audit and run provenance. Fit observational association models, never claim causality. Log changed research decisions in research/decision-log.md.

Use Python/DuckDB for source audit, metric CRS for spatial work, and globally optimal multi-source shortest paths for nearest reachable entrance. Test directed/disconnected graphs. Export only aggregates meeting privacy thresholds. Fail closed on incomplete quality gates. Run Python tests, TypeScript checks, web build and browser smoke checks after relevant changes. Never push without user authorization. Do not erase source artifacts or rewrite earlier results.
