# متروپریمیوم

**خونه نزدیک مترو واقعاً گرون‌تره؟**

بررسی رابطه قیمت آگهی‌های مسکن و دسترسی به مترو در تهران با استفاده از داده‌های عمومی دیوار، شبکه معابر شهری و الگوریتم‌های علوم شبکه.

این نسخه یک پیش‌نمایش پژوهشیِ قابل اجراست. هنوز نتیجه‌ای درباره رابطه قیمت مسکن و مترو ندارد. فایل رسمی دیوار به‌طور کامل دریافت و ممیزی شده است: یک میلیون ردیف و ۶۰ ستون. ۸۴٬۵۸۶ آگهی مربوط به فروش آپارتمان در تهران است. پس از انتخاب دسامبر ۲۰۲۴ و فیلتر قیمت مقطوع مثبت و مساحت ۲۰ تا ۵۰۰ متر، ۱۱٬۷۶۷ ردیف باقی مانده است.

واحد پول و معنای دقیق «قیمت کل» برای این خروجی رسمی تأیید نشده است. بنابراین قیمت هر مترمربع، تبدیل تومان/ریال، رتبه‌بندی محله‌ها و ضرایب رگرسیون تجربی نمایش داده نمی‌شوند. این تصمیم به معنی بی‌ارزش بودن داده نیست؛ نتیجه باید با شواهد قابل دفاع باشد.

داده هفت رابطه مسیر مترو دریافت شده است. شبکه آزمایشی معابر واقعی ۶۶۶ گره و ۱٬۴۵۲ یال جهت‌دار دارد. نقشه عمومی فقط همان محدوده کوچک را نمایش می‌دهد. خطوط مترو تا تأیید مستقل هندسه، اتصال و زمان بهره‌برداری غیرفعال هستند. شبکه مرجع سال ۲۰۲۶ است و نباید دسترسی تاریخی سال ۲۰۲۴ تلقی شود.

## اجرا

Node و Python و uv را نصب کنید، سپس:

```sh
node scripts/task.mjs setup
npm run dev
```

نشانی محلی: http://127.0.0.1:5173

```sh
node scripts/task.mjs smoke
node scripts/task.mjs test
npm run test:e2e
```

آزمون smoke کاملاً ساختگی است و از نتایج واقعی جدا نگه داشته می‌شود. برای بازتولید ممیزی رسمی:

```sh
node scripts/task.mjs acquire
node scripts/task.mjs audit-data
node scripts/task.mjs acquire-osm
node scripts/task.mjs reproduce --offline
```

هیچ آگهی‌ای از سایت زنده دیوار خزش نمی‌شود. موقعیت و شرح آگهی‌ها وارد خروجی عمومی نمی‌شوند. محله‌های کمتر از ۳۰ آگهی نمایش داده نمی‌شوند. داده‌ها تاریخی و قیمت‌ها پیشنهادی هستند؛ معامله قطعی و اثر علّی اندازه‌گیری نشده است.
