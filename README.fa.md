# متروپریمیوم

**خانه نزدیک مترو واقعاً گران‌تر است؟**

[وب‌سایت فارسی](https://houtanrocky.github.io/metro-premium/?lang=fa) · [English website](https://houtanrocky.github.io/metro-premium/?lang=en) · [مخزن گیت‌هاب](https://github.com/houtanrocky/metro-premium)

بررسی رابطه قیمت آگهی‌های مسکن و دسترسی به مترو در تهران با استفاده از داده‌های عمومی دیوار، شبکه معابر شهری و الگوریتم‌های علوم شبکه.

این نسخه یک پیش‌نمایش پژوهشیِ قابل اجراست. تحلیل اکتشافی فاصله تا زیرمجموعه ورودی‌های ثبت‌شده در نقشه تاریخی اکنون اجرا شده؛ نتیجه اصلی درباره دسترسی عملیاتی مترو هنوز تأیید نشده است. فایل رسمی دیوار به‌طور کامل دریافت و ممیزی شده است: یک میلیون ردیف و ۶۰ ستون. ۸۴٬۵۸۶ آگهی مربوط به فروش آپارتمان در تهران است. پس از انتخاب دسامبر ۲۰۲۴ و فیلتر قیمت مقطوع مثبت و مساحت ۲۰ تا ۵۰۰ متر، ۱۱٬۷۶۷ ردیف باقی مانده است.

پس از بررسی نمونه واقعی، مالک پروژه تأیید کرد که قیمت‌ها به تومان و برای کل آپارتمان هستند. این تأیید با منبع و تاریخ ثبت شده و به ناشر داده نسبت داده نمی‌شود. قیمت هر مترمربع با تقسیم قیمت کل بر مساحت محاسبه می‌شود. در نمونه دسامبر ۲۰۲۴، میانه حدود ۸۷ میلیون تومان و بازه میانی ۵۰٪ حدود ۵۸٫۵ تا ۱۲۶٫۷ میلیون تومان در مترمربع است. تحلیل جداگانه ورودی‌های ثبت‌شده، ۲٬۹۷۸ مسیر و ۲٬۹۶۲ مشاهده کامل برای مدل‌ها دارد. بازه مدل تعدیل‌شده با محله دو سوی صفر را پوشش می‌دهد و برخی جابه‌جایی‌های فرضی مکان، علامت برآورد را تغییر می‌دهند؛ پریمیوم عملیاتی مترو یا اثر علّی اثبات نشده است.

شبکه آزمایشی معابر واقعی ۶۶۶ گره و ۱٬۴۵۲ یال جهت‌دار دارد و نقشه عمومی همان محدوده کوچک سال ۲۰۲۶ را نمایش می‌دهد. تحلیل اکتشافی جداگانه، نقشه بایگانی‌شده با تاریخ درخواست اول دسامبر ۲۰۲۴ را به کار می‌گیرد: ۵۵۵٬۶۸۶ گره، ۱٬۲۳۶٬۷۸۰ یال و ۱۶۶ ورودی نگه‌داشته‌شده. بخشی از فایل‌ها از خروجی مرورگر مالک وارد شده‌اند و این نوع شواهد صریحاً ثبت شده است. وجود در نقشه، بهره‌برداری تاریخی یا کامل بودن ورودی‌ها را تأیید نمی‌کند. خطوط مترو تا تأیید مستقل هندسه، اتصال و زمان بهره‌برداری غیرفعال هستند. [یافته‌های اکتشافی و محدودیت‌ها](research/mapped-reference-findings.md).

رابط کاربری به فارسی و انگلیسی در دسترس است. متن‌های سایت در فایل‌های `apps/web/src/locales/fa.json` و `en.json` نگهداری می‌شوند. تغییر زبان، جهت صفحه و قالب اعداد را هم تغییر می‌دهد و انتخاب شما ذخیره می‌شود. برای پیوند مستقیم از `?lang=fa` یا `?lang=en` استفاده کنید. [راهنمای انتشار](docs/deployment.md).

## اجرا

Node و Python و uv را نصب کنید، سپس:

```sh
node scripts/task.mjs setup
npm run dev
```

نشانی محلی: http://127.0.0.1:5173

```sh
node scripts/task.mjs smoke
node scripts/task.mjs test
npm run test:e2e
```

آزمون smoke کاملاً ساختگی است و از نتایج واقعی جدا نگه داشته می‌شود. برای بازتولید ممیزی رسمی:

```sh
node scripts/task.mjs acquire
node scripts/task.mjs audit-data
node scripts/task.mjs acquire-osm
node scripts/task.mjs reproduce --offline
```

برای بازتولید تحلیل اکتشافی پس از دریافت و ادغام فایل‌های تاریخی:

```sh
node scripts/task.mjs reproduce --config configs/mapped-reference.yaml --offline
```

هیچ آگهی‌ای از سایت زنده دیوار خزش نمی‌شود. موقعیت و شرح آگهی‌ها وارد خروجی عمومی نمی‌شوند. محله‌های کمتر از ۳۰ آگهی نمایش داده نمی‌شوند. داده‌ها تاریخی و قیمت‌ها پیشنهادی هستند؛ معامله قطعی و اثر علّی اندازه‌گیری نشده است.
